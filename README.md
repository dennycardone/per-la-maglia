# Per la Maglia

Ogni tuo gol vale per la tua squadra. Scegli la tua squadra del cuore, scavalca il portiere col cucchiaio e porta punti alla classifica settimanale dei tifosi.

Gioca: https://perlamaglia.com/

## Pubblicare su GitHub Pages

1. Carica in questo repository tutti i file: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`.
2. Vai in **Settings → Pages**, scegli **Deploy from a branch**, ramo `main`, cartella `/ (root)`.
3. Dopo un paio di minuti il gioco è online su `https://<utente>.github.io/<repository>/`.

## Installarlo sul telefono

- **Android (Chrome):** apri il link e tocca **Installa app** (o menu ⋮ → Aggiungi a schermata Home).
- **iPhone (Safari):** apri il link, tocca Condividi → **Aggiungi alla schermata Home**.

Dopo la prima apertura il gioco funziona anche senza connessione.

## Classifica

Su GitHub Pages la classifica è salvata sul telefono di ciascun giocatore. Per una classifica condivisa tra tutti serve un server (per esempio Supabase).
